208 EICAS DESKTOP - NATIVE TEST BUILD

External engine-management and startup companion for Microsoft Flight
Simulator 2024 and the Black Square Caravan Professional.

This edition uses a native Windows interface. It does not launch a browser,
host a website, run a local HTTP server, or reserve port 8765.

TESTING
-------
1. Extract the complete folder.
2. Keep 208 EICAS Desktop.exe and SimConnect.dll together.
3. Start MSFS 2024 and load the Black Square Caravan Professional.
4. Run 208 EICAS Desktop.exe.

Closing the window hides it in the Windows notification area. Double-click
the existing 208 tray icon to reopen it, or right-click the icon and choose
Exit. The PWR button must be held for 1.2 seconds to shut down the application.

This is a conversion test build. Keep the previously tested browser edition
available as a rollback while checking layout, scaling, startup sequencing,
alerts, cruise guidance, event logging, dimming, and tray behavior.

IMPORTANT
---------
208 EICAS is a read-only supplemental reference. It does not control the
aircraft and is not a certified flight instrument. Always follow the aircraft
manual and in-simulator checklists.
